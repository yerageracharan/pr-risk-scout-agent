# Security Policy

Do not publicly disclose working credentials, exploit details, private pull-request diffs, or confidential repository contents.

Use GitHub's Security tab and **Report a vulnerability** flow for private disclosure when private vulnerability reporting is enabled. If unavailable, contact the repository owner privately through their GitHub profile and request a secure route. Do not publish details while arranging contact.

Include the affected commit/version, exact parser or rule path, a minimal reproduction using synthetic diff content, demonstrated impact, and redacted logs.

This tool is advisory and read-only. A rule match alone is not a verified vulnerability. Reports should demonstrate an actual boundary failure or unsafe handling in this tool, not simply show that a scanned diff contains risky code.
